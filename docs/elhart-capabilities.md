# Подтверждённые возможности Elhart MCP

Дополнение 23 октября 2026: USB-загрузка ECP-10 через штатный FSTools — **pilot**.
Проверены изолированная сборка отдельной копии, dry-run настоящего загрузчика,
считывание его контролов и завершение. Физическая передача не выполнялась,
аппаратная приёмка ожидается. Четыре новых инструмента и ограничения описаны
в [порядке загрузки](panel-download.md).

MCP 0.5.0, ELHART HMI Soft 3.0.15569.0, Windows/.NET Framework x86.
Дата проверок: 14–15 октября 2026. Основной тестовый профиль — ECP10/F010,
ID2050, OEM119, 1024×768, runtime a8. Каталог сообщает 16-битный цвет.
GUID локального устройства берётся из проекта; фабрики подтверждают
Raw LB=254 и Raw LW=65791.
