# Подтверждённые возможности Elhart MCP

MCP 0.5.0, ELHART HMI Soft 3.0.15569.0, Windows/.NET Framework x86.
Дата проверок: 14 октября 2026. Основной тестовый профиль — ECP10/F010,
ID2050, OEM119, 1024×768, runtime a8. Каталог сообщает 16-битный цвет.
GUID локального устройства берётся из проекта; фабрики подтверждают
Raw LB=254 и Raw LW=65791.

| Возможность | Подтверждение | Граница |
| --- | --- | --- |
| MCP stdio, tools/list, health | Чистая поставка, 81 инструмент, реальные запросы | Список не доказывает все операции |
| Плагин в редакторе | Отдельный endpoint, PID, workspace и текущий проект | Смена разных проектов ещё требует отдельной проверки |
| Создание проекта | Нативный HMIProjectCreator, OEM ECP10 | Проверен этот профиль и версия |
| Сохранение и открытие | Штатные сервисы, старые ref отклоняются | Другие способы переключения не подтверждены |
| Русский текст, числовые поля | Пакетное создание, сохранение, открытие, сборка | Фактический ввод и отображение крайних значений ожидают симулятора |
| Битовая кнопка | Действие LB20, два полных состояния и подписи | Реальные нажатия ещё не проверены |
| Словный индикатор | LW102, 0/1 и ShowErrorState, три круга 64×64, пустые теги | Фактическая смена состояния ещё не проверена |
| Знаковое число | Int16 в модели и адресе, IsShowZero, −32768…32767 | Отображение значений ещё не проверено |
| PNG с alpha | LoadFromFile, PictureOrigin=File, сохранение и сборка | Вид прозрачности в симуляторе ещё не проверен |
| Переход страницы | Window/KeyDown/Switch и целевой UUID сохранены | Сам переход в симуляторе ещё не проверен |
| История и имена | Пакетный undo/redo сохраняет UUID; дубли создания отклонены | Создание не является upsert |
| Полная сборка | Успех, реальная ошибка, отмена, хеши, сохранность исходников и очистка | Сверка с ручной сборкой и визуальная приёмка остаются |
| Офлайн-симулятор | Нативный вызов, процессы FCS/FSGUI, данные сохранены | Снимки и взаимодействие ещё не получены |
| Жизненный цикл теста | Точный PID/токен, сохранение перед закрытием, собственное дерево процессов | Чужие проекты при очистке не завершаются |
| Демо SLM | DTO/модели, макрос Win32/ARM, действия и тесты времени/памяти, полная сборка копии | Приёмка в симуляторе ещё в работе |
| Панель/PLC/download | Не проверено | Не заявляется поддержка по результатам симулятора |

Исторические сертификаты FStudio 3.0.15685.0 описывают другую установку.
В [отчёте](elhart-validation.md) указаны отдельные сценарии и результаты.
Оставшиеся обязательные проверки сохранены в [PLAN.md](../PLAN.md).
