# Приёмка с участием оператора

Когда захват Computer Use недоступен, оператор выполняет нажатия в настоящем
симуляторе и сообщает результаты. MCP продолжает открывать копию проекта,
проверять плагин, сохранять и собирать проект. Это ручная проверка интерфейса,
а не успешное испытание Computer Use.

## Одна тестовая сессия

В рабочей копии Git команда
`python tests/manual_acceptance.py <новое-имя> <проект-в-workspace>` копирует исходники
в новую папку projects, открывает собственный редактор с плагином, выполняет
полную нативную сборку и запускает офлайн-симулятор один раз. Исходник сохраняется.
Нативный результат сохраняется локально в artifacts/manual-acceptance.
Появление ready.json не подтверждает визуальную или интерактивную приёмку.

Сессия ждёт оператора до 30 минут или файла stop в своей папке отчёта.
Затем сохраняет проект и закрывает только своё дерево после нативного
подтверждения сохранения и закрытия. При ошибке очистки результат сообщает
об ошибке; нельзя запускать дубликат вместо восстановления текущей сессии.
Оператору не требуется самостоятельно открывать второй редактор.
Сам вспомогательный тестовый runner не входит в ZIP исходников MCP;
чеклист оператора включён. Для разработки runner запускают из Git checkout.

## Представительный экран

Проверки выполняются небольшими группами, с ответом оператора после каждой.

| Действие | Ожидаемый результат |
| --- | --- |
| Открыть числовой ввод справа от значения с единицей «мбар» | Открывается нативная цифровая клавиатура |
| По очереди ввести 0, −123, 32767 и подтвердить | Слева отображается точное значение, включая ноль и знак; единица не перекрывает цифры |
| Ввести −32768 | Минимум Int16 корректно отображается |
| Попробовать значение вне −32768…32767 | Значение не принимается как допустимое; записать фактическое поведение клавиатуры |
| Нажать кнопку «Пуск», затем повторить | Проверить фактические состояния 0/1 и подписи; записать поведение при удержании и отпускании |
| В поле состояния ввести 0, 1, 99 | Круг серый, зелёный, резервный янтарный; форма круглая, скрытых подписей нет |
| Перейти на вторую страницу и вернуться | Переходы работают, значения и состояние сохраняются |
| Осмотреть русские подписи и прозрачную картинку | Нет обрезанного текста, искажений пропорций или непрозрачного фона |

Оператор сообщает фактические результаты, ошибки и расхождения. Для сохранения
реальных экранов оператор предоставляет снимки симулятора. Геометрический
рендер, DTO и сообщения о запуске не заменяют эти снимки.

## Демо SLM

После проверки представительного экрана закрыть его сессию и запустить одну
сессию копии SLM. Проверить пять страниц, подготовку/пуск/останов, затвор,
воздуходувку, таймеры, состояния кнопок и подтверждение команд. Сравнить
ход времени с независимыми часами при переключениях страниц; сохранить
отдельную проверку макроса 10×100 мс и повторных вызовов.

Каждому подтверждению указывать источник: нативная сборка, автоматизированный
тест макроса, наблюдение оператора или снимок реального симулятора. Ручная
приёмка офлайн-демо не подтверждает физическую панель и связь с ПЛК.
