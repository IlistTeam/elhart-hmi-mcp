# ELHART HMI MCP

MCP-сервер для создания и изменения нативных проектов **ELHART HMI Soft**.
Публичный форк [TingRuazhang/FStudio_MCP](https://github.com/TingRuazhang/FStudio_MCP),
адаптируемый для панелей ELHART ECP.

## Статус проекта

**План адаптации выполнен 15 октября 2026 года** для ELHART HMI Soft 3.0.15569.0
и ECP-10/F010, OEM119, 1024×768. Профиль Elhart, нативное создание
проекта и компонентов, сохранение, повторное открытие и полная компиляция
проверены. MCP 0.5.0 предоставляет 82 инструмента. Оператор подтвердил
сценарии представительного экрана и пятистраничного SLM в настоящем симуляторе,
включая крайние значения, прозрачность PNG, время и аварийные блокировки.
Итоговые результаты и границы проверки: [итоговый отчёт](docs/elhart-final-results.md).
Критерии закрыты в [плане разработки](PLAN.md).

Предварительное исследование на ELHART HMI Soft **3.0.15569.0** подтвердило:

- сборку C#-моста и плагина с установленными библиотеками Elhart;
- инициализацию MCP, список из 73 инструментов и вызов health;
- чтение 40 окон и четырёх конфигурационных файлов без изменения исходников;
- прохождение 12 офлайн-тестов и 26 сценариев доступа к моделям.

Новые испытания Elhart подтвердили создание ECP-10, русский текст,
числовые поля, локальные адреса, двухсостояниевую кнопку, сохранение,
повторное открытие и полную изолированную компиляцию. Нативный импорт PNG,
действие перехода между страницами и отмена/повтор проверены после сохранения.
34 регрессионных теста прошли. Подробности и границы проверки — в
[отчёте адаптации](docs/elhart-validation.md).

Подтверждённые сценарии и оставшиеся границы:
[таблица возможностей](docs/elhart-capabilities.md).

Результаты испытаний оригинального FStudio 3.0.15685.0 учитываются отдельно.

Первый целевой сценарий: **ECP-10, 1024×768**, демонстрация станции загрузки
порошка SLM с обновлением каждые **100 мс**.

## Возможности

- Создание, открытие и сохранение редактируемых проектов .fsprj.
- Создание страниц, текста, кнопок, индикаторов и числовых полей.
- Пакетное изменение оформления, размеров, положения и свойств компонентов.
- Настройка адресов внутренней памяти, действий и состояний.
- Импорт изображений и чтение фактической геометрии страницы.
- Компиляция сохранённого снимка проекта с журналом и результатами.
- Проверка интерфейса и взаимодействия в симуляторе Elhart.

Подтверждения относятся к выбранным сценариям и указанной версии Elhart;
наличие 82 инструментов не означает проверку каждой их комбинации.

## Архитектура

| Компонент | Назначение |
| --- | --- |
| Python 3.11+ | Протокол stdio MCP, проверка параметров и управление задачами |
| C# / .NET Framework x86 | Чтение DTO и плагин с доступом к штатным моделям редактора |
| Локальный named pipe | Связь Python-сервера с плагином Elhart |
| Изолированная сборка | Компиляция копии сохранённого проекта и сбор доказательств |
| Навык Elhart | Требования, оформление, выбор инструментов и приёмка |

Компоненты создаются через штатные модели и фабрики. Специальные правки XML
должны сохранять пространства имён, порядок полей DTO, действия и состояния.

## Среда разработки

- Windows с установленным ELHART HMI Soft; первая целевая версия — 3.0.15569.0.
- Python 3.11 или новее.
- .NET Framework 4.x и компилятор x86.
- Клиент с поддержкой stdio MCP.

Профиль Elhart использует установленный каталог OEM 119. Сборка моста
и плагина по умолчанию выбирает установку KIP. Согласование workspace,
диагностика и дальнейшая приёмка описаны в [PLAN.md](PLAN.md); полноценная
поставка исходников и интеграция навыка проверены в отдельной чистой папке.

Инструкции сборки, подключения, обновления и восстановления:
[установка Elhart MCP](docs/elhart-installation.md).
