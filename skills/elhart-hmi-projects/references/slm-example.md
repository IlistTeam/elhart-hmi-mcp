# Пример для быстрого старта

assets/slm-ecp10-starter.zip — станция загрузки порошка с исправлением
сохраняемой временной базы макроса от 14.10.2026.
Исключены Bin/Subbin/temp, история исправлений, концепты, рендеры и старые
генераторы. Выполни полную компиляцию после извлечения.

ECP10 1024×768, окна Авто 1, Ручной 2, Журнал 3, Настройки 4, Калибровка 5;
228 компонентов и штатные служебные окна. Только внутренняя память,
100 мс, MM:SS.d; основные кнопки/значения редактируются в Elhart.

```text
python scripts/project_tool.py starter --out <новая-папка> --name PowderLoader
python scripts/project_tool.py xml-check --project <новая-папка>
```

Затем изменяй нужные экраны/логику. Копия сохраняет GUID внутри собственного
проекта; перед объединением с другим проектом ремаппируй ID и ссылки.
Для другого оборудования бери прототипы компонентов, а не весь цикл SLM.
Тесты scripts/slm_checks привязаны к этому примеру и конкретным ID/размерам.

## Карта демо, не карта PLC

Устройство 773c97c2-47bb-4ea9-bff0-80a34babe3df; словаLW1000,
командыLB1000, статусыLB1100.

| Смещение слова | Значение |
| --- | --- |
| 0…3 | MAGIC, состояние, возраст этапа/сек, RUN/сек |
| 4…8 | O2/сотые %, давление перед воздуходувкой, бункера, °C, % затвора |
| 9…14 | воздуходувка, затвор, подпитка, порошок, связь, аварийная цепь |
| 15…24 | газ, фильтр, сообщение, журнал, сеанс, материал, fault, калибровка |
| 30 / 40 | сохранённые / редактируемые настройки |
| 60…63 | MM:SS.d, четыре слова |
| 65…67 / 72…77 | лимит / дата |
| 80…83 | этапы: ожидание 0, активен 1, завершён 2 |
| 84…87 | сохраняемая временная база макроса; зарезервировано, не использовать для команд/индикации |
| 100 / 300 | опубликованные данные / кольцо журнала |

Команды 0…24: START,STOP,CLEAN,FAN,VALVETOGGLE,MINUS,PLUS,CLOSEGATE,
MAKEAUTO,MAKEMANUAL,SAVECFG,CANCELCFG,GASCHANGE,MATERIALCHANGE,CALOPEN,
CALNEXT,CALCLOSE,ALL,WARN,ALARM,EXPORT,RESET,DEMOFAULT,ACK,EMERGENCY.
Статусы 100…134; команды 0…24 не стирать массовой записью.
Полная карта/алгоритм в извлечённом slm_demo.c.

CHECK2 с → FLOW4 с → LOAD45 с → PURGE5 с, очистка 3 с. Не переносить
времена в другой процесс без его требований. Старый генератор 1024×600
не включён: его запуск поверх адаптации возвращал бы старую компоновку.

Калибровка завершается строкой «5. Демонстрация завершена» на экране,
а не отдельным всплывающим диалогом. Событие завершения добавляется в журнал
однократно при переходе 4→5; повторное «Следующий шаг» после завершения
не меняет журнал. Это проверяется регрессией. В подписи теста аварии
используется O2: нижний индекс O₂ не отображался выбранным шрифтом симулятора.
